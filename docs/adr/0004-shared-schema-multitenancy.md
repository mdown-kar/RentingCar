# 0004 — Shared schema multi-tenancy

## Context

We want to connect multiple agencies. Every agency has its account and has its own data. But the data of an agency does not need to be reached or be checked by other agencies. So we need security for that.

## Decision

So doing multi-tenancy will fix this, but we know with good programming and good security with it we can fix it. A database with multi-tenancy is a fix for this problem.

## Consequences

More work, but that is not very bad. If you started at the beginning, you can make it easier.

## Status

Accepted, 2026-08-21.
