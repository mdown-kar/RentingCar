# 0001 — PostgreSQL over MySQL

## Context

Bug that I prevent is when 2 people or cnx problem rent same car 2 times that will break my app and mislead payment in the end.

## Decision

PostgreSQL, have the answer and you can never book same car in same period 2 times that will fix it now I have new layer to protect my database by PostgreSQL.

## Consequences

I know MySQL better but I decided to use PostgreSQL because it keeps the data correct and it will protect my app from this bug learning new thing is an option for me.
